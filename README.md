# CrypTrader 🚀

Simulador de trading y predicción de criptomonedas con integración de:
- 📊 Datos históricos de precios y volumen
- 🤖 Modelos de Machine Learning (RandomForest / LSTM)
- 📰 Análisis de noticias y sentimiento del mercado
- 🌐 Deploy automático en Hugging Face y GitHub

## Características principales
- Soporte para múltiples cryptos (BTC, ETH, SOL, etc.)
- Predicciones basadas en datos históricos + contexto de noticias
- Visualización de velas y métricas clave
- Integración modular para mejorar precisión
